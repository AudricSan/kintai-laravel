# Changelog

## 1.0.0

Reconstruction en package Laravel natif à partir du bundle `notebook` 3.0.0 de l'ancien framework : page Livewire + Flux, widgets de tableau de bord, droits avec portée magasin, fonctionnalité de magasin, notification et journal via le contrat 1.1 (`Notifier`). Expiration par jour (`expires_on`) au lieu d'un horodatage. API REST non reprise.
