# Changelog

## 1.0.0

Reconstruction en package Laravel natif à partir du bundle `team-directory` 3.0.0 de l'ancien framework : écrans Livewire + Flux, profil d'équipe dans une table du bundle (colonnes `bio`, `skills`, `languages_spoken`, `hobbies`, `show_in_directory` sorties de `users`), visibilité via `ColleagueDirectory` du contrat 1.1, fonctionnalité de magasin, journal, effacement à l'anonymisation.
