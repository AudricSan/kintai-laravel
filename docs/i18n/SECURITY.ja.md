# セキュリティポリシー

🌐 [English](../../SECURITY.md) · [Français](SECURITY.fr.md) · **日本語**

## サポート対象バージョン

Kintaiは現在`1.0.0`未満のプレリリース段階であり、長期サポートブランチはまだ存在しません。これまでのリリースはすべて
`alpha` または `beta` チャンネルで公開されたプレリリースです（[リリース](https://github.com/AudricSan/Kintai/releases)）。
セキュリティ修正は次のリリースに含まれ、各インスタンスは `/admin/update` の**今すぐアップデート**で適用できます。

| バージョン | サポート状況 |
|---------|-----------|
| 最新の公開リリース（alpha または beta チャンネル） | ✅ |
| それ以前のリリース | ❌ |

`main` で `1.0.0` が公開された後は、最新の安定版リリースがサポート対象になります。

## 脆弱性の報告

**セキュリティ上の脆弱性については、公開issueを作成しないでください。**

GitHubの非公開脆弱性報告機能をご利用ください：
👉 [脆弱性を報告する](https://github.com/AudricSan/Kintai/security/advisories/new)

報告には以下を含めてください：
- 脆弱性の説明
- 再現手順
- 想定される影響
- 修正案（任意）

72時間以内に返信いたします。問題が確認され、修正版がリリースされた後、報告者への謝辞とともに脆弱性を公表します（匿名を希望される場合はその旨をお知らせください）。
