# Politique de sécurité

🌐 [English](../../SECURITY.md) · **Français** · [日本語](SECURITY.ja.md)

## Versions supportées

Kintai est actuellement en pré-`1.0.0` — il n'existe pas encore de branche de support à long terme, et toutes les
releases publiées jusqu'ici sont des pré-releases, sur le canal `alpha` ou `beta`
([releases](https://github.com/AudricSan/Kintai/releases)). Les correctifs de sécurité partent dans la release
suivante ; les instances les reçoivent via **Mettre à jour maintenant** sur `/admin/update`.

| Version | Supportée |
|---------|-----------|
| Dernière release publiée (canal alpha ou beta) | ✅ |
| Toute release antérieure | ❌ |

Une fois la `1.0.0` publiée sur `main`, la version supportée sera la dernière release stable.

## Signaler une vulnérabilité

**Merci de ne pas ouvrir d'issue publique pour signaler une vulnérabilité de sécurité.**

Utilisez le signalement privé de GitHub :
👉 [Signaler une vulnérabilité](https://github.com/AudricSan/Kintai/security/advisories/new)

Incluez dans votre rapport :
- Description de la vulnérabilité
- Étapes de reproduction
- Impact potentiel
- Correctif suggéré (optionnel)

Vous recevrez une réponse sous 72 heures. Une fois le problème confirmé et un correctif publié, nous divulguerons publiquement la vulnérabilité en créditant la personne à l'origine du signalement (sauf si vous préférez rester anonyme).
